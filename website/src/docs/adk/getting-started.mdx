# Getting Started

The ADK provider brings on-device Gemini Nano to Android React Native apps through [Google's Agent Development Kit (ADK)](https://developer.android.com/ai/adk) and the Vercel AI SDK. Gemini Nano runs locally via ML Kit GenAI - provisioned by the Android system through AICore, with no API key and no model files to bundle. You can also use cloud Gemini when you need a larger model or broader device support.

## Installation

Install the ADK provider:

<PackageManagerTabs command="install @react-native-ai/adk" />

You can use the ADK provider standalone, but we recommend the Vercel AI SDK for its unified APIs and streaming. To use it with the AI SDK, you'll need v7+ and [required polyfills](../polyfills.md):

<PackageManagerTabs command="install ai" />

## Requirements

- **Android only** - The provider is not available on iOS or web
- **Android `minSdkVersion` 26 or greater** - Required by ML Kit GenAI
- **React Native New Architecture** - Required for native module functionality
- **React Native 0.76 or later**

:::danger Gemini Nano - physical supported device required
Gemini Nano requires a physical Android device with AICore and Gemini Nano support. Please consult the [ML Kit GenAI documentation](https://developers.google.com/ml-kit/genai#feature-device).

Cloud Gemini works on any Android device or emulator once you configure an API key.
:::

## App Configuration

Consuming apps must set `minSdkVersion` to at least 26. ADK pulls in Google GenAI libraries that duplicate `META-INF/INDEX.LIST` and `META-INF/DEPENDENCIES`, so exclude them from your app packaging.

### Expo

Configure `expo-build-properties` in your app config:

```json
{
  "expo": {
    "plugins": [
      [
        "expo-build-properties",
        {
          "android": {
            "minSdkVersion": 26,
            "packagingOptions": {
              "exclude": ["META-INF/INDEX.LIST", "META-INF/DEPENDENCIES"]
            }
          }
        }
      ]
    ]
  }
}
```

Then regenerate the native project:

```bash
npx expo prebuild --clean
```

### Bare React Native

Add the following to `android/app/build.gradle` and make sure `minSdkVersion` is at least 26:

```groovy
android {
  packagingOptions {
    excludes += ["META-INF/INDEX.LIST", "META-INF/DEPENDENCIES"]
  }
}
```

## Available Model Types

| Model Type            | `modelType`  | Default `modelName` | Use Case                                                           |
| --------------------- | ------------ | ------------------- | ------------------------------------------------------------------ |
| On-device Gemini Nano | `genai-nano` | `gemini-nano`       | Private, offline-capable inference - system-provisioned via AICore |
| Cloud Gemini          | `gemini`     | `gemini-2.5-flash`  | Cloud inference via the Gemini API                                 |

When you set `modelName` to anything other than `gemini-nano`, `modelType` defaults to `gemini`.

## Basic Usage

Import the default ADK provider and call `adk()` to construct a language model, then pass it to the AI SDK. The default provider targets on-device Gemini Nano:

```typescript
import { adk } from '@react-native-ai/adk'
import { generateText } from 'ai'

const { text } = await generateText({
  model: adk(),
  prompt: 'Summarize on-device AI in one sentence.',
})
```

Pass a model name or options to `adk()` to pick a model per call site, like `apple()`:

```typescript
const nano = adk()
const flash = adk({ modelName: 'gemini-2.5-flash', apiKey })
```

Before you offer Gemini Nano in your UI, check that the device supports it and that it is ready. See [Availability](#availability) below.

## On-device Gemini Nano

Gemini Nano runs locally via ML Kit GenAI and is provisioned by the Android system through AICore. To set a system instruction, create a provider with `createAdkProvider`. ADK passes it to ML Kit as a native system instruction:

```typescript
import { createAdkProvider } from '@react-native-ai/adk'
import { generateText } from 'ai'

const adk = createAdkProvider({
  instruction: 'You are a helpful assistant.',
})

const { text } = await generateText({
  model: adk(),
  prompt: 'Summarize on-device AI in one sentence.',
})
```

### Availability

`adk.getModelInfo()` reports whether Gemini Nano can be used, based on the ML Kit [`FeatureStatus`](https://developers.google.com/android/reference/com/google/mlkit/genai/common/FeatureStatus):

```typescript
import { adk } from '@react-native-ai/adk'

const info = await adk.getModelInfo()

switch (info.availability) {
  case 'available':
    // Ready to generate
    break
  case 'downloadable':
    // Offer a download - adk.prepareNano() downloads it
    break
  case 'downloading':
    // Show as unavailable until the download finishes
    break
  case 'unavailable':
  case 'unknown':
    // The device cannot run Gemini Nano - hide it from the model picker
    break
}
```

| `availability` | `FeatureStatus`    | Meaning                                      |
| -------------- | ------------------ | -------------------------------------------- |
| `available`    | `AVAILABLE` (3)    | Downloaded and ready                         |
| `downloadable` | `DOWNLOADABLE` (1) | Supported, `prepareNano()` downloads it      |
| `downloading`  | `DOWNLOADING` (2)  | The system is downloading it                 |
| `unavailable`  | `UNAVAILABLE` (0)  | Not supported on this device, or not Android |
| `unknown`      | -                  | ML Kit could not report a status             |

When Gemini Nano is `available`, `getModelInfo()` also returns `baseModelName` and `contextSize` (the input token limit). For cloud Gemini, `getModelInfo({ modelType: 'gemini' })` always reports `available` on Android.

The provider also has two yes/no shortcuts:

| API                             | Resolves to `true` when                                      |
| ------------------------------- | ------------------------------------------------------------ |
| `adk.isNanoSupported()`         | The device can run Gemini Nano, even if it is not downloaded |
| `adk.isAvailable('genai-nano')` | Gemini Nano is `available` or `downloadable`                 |

All of these are cheap native calls that do not download the model. You can cache them at app startup and check again when the app resumes.

### Preparation

`adk.prepareNano()` downloads and initializes Gemini Nano, and can report download progress:

```typescript
import { adk } from '@react-native-ai/adk'

await adk.prepareNano({
  onProgress: ({ phase, bytesDownloaded, bytesToDownload }) => {
    // phase is 'started', 'progress' or 'completed'
  },
})
```

Calling `model.prepare()` on a model prepares it too, and `generateText()` and `streamText()` prepare the model automatically on first use:

```typescript
import { adk } from '@react-native-ai/adk'
import { generateText } from 'ai'

const model = adk()

// Prepare explicitly, for example while showing a loading state
await model.prepare()

// Or let the first generation prepare the model
await generateText({ model, prompt: 'Hello!' })
```

Preparation fails with a `MODEL_UNAVAILABLE` error on unsupported devices and `MODEL_DOWNLOADING` when the system is still downloading. See [Errors](#errors).

### Model Selection

ML Kit can run a preview Gemini Nano model or favor speed over quality. Set `nano` on the provider or the model:

```typescript
import { createAdkProvider } from '@react-native-ai/adk'

const adk = createAdkProvider({
  nano: { releaseStage: 'preview', preference: 'full' },
})
```

| Option         | Values                            | Description                                                   |
| -------------- | --------------------------------- | ------------------------------------------------------------- |
| `releaseStage` | `'stable'` (default), `'preview'` | Preview models need the AICore developer preview              |
| `preference`   | `'fast'`, `'full'`                | `fast` favors latency, `full` favors quality and capabilities |

Availability depends on the selected model, so `getModelInfo()`, `isAvailable()` and `prepareNano()` use the provider's `nano` setting.

### Token Counting

`model.countTokens(text)` counts tokens with the Gemini Nano tokenizer. Compare it with `contextSize` from `getModelInfo()` before you send a long prompt:

```typescript
const model = adk()
const tokens = await model.countTokens(longText)
```

Cloud models do not support token counting.

## Cloud Gemini

When you need cloud inference - for example on emulators or devices without AICore - create a provider with `modelType: 'gemini'` and an API key:

```typescript
import { createAdkProvider } from '@react-native-ai/adk'
import { generateText } from 'ai'

const adk = createAdkProvider({
  apiKey: process.env.GOOGLE_API_KEY,
  modelType: 'gemini',
  modelName: 'gemini-2.5-flash',
  instruction: 'You are a helpful assistant.',
})

const { text } = await generateText({
  model: adk(),
  prompt: 'What time is it in New York?',
})
```

Cloud models do not need a download or prepare step. ADK retries transient Gemini API failures.

> Do not embed API keys in production client apps. Prefer a backend proxy or secure runtime configuration.

## Provider Options

`createAdkProvider` sets defaults for every model it creates. Call `adk()` or `adk.languageModel()` to construct a language model, optionally overriding any option:

```typescript
import { createAdkProvider } from '@react-native-ai/adk'

const adk = createAdkProvider({
  name: 'my_agent',
  description: 'A helpful assistant',
  instruction: 'You are a concise, friendly assistant.',
})

const model = adk.languageModel({ instruction: 'Answer in one word.' })
```

| Option           | Type                       | Description                                                                                   |
| ---------------- | -------------------------- | --------------------------------------------------------------------------------------------- |
| `name`           | `string`                   | ADK agent name (default: `react_native_adk_agent`)                                            |
| `description`    | `string`                   | Agent description passed to ADK                                                               |
| `instruction`    | `string`                   | System instruction for the agent                                                              |
| `modelType`      | `'genai-nano' \| 'gemini'` | On-device or cloud backend (default: `genai-nano`, or `gemini` for other model names)         |
| `modelName`      | `string`                   | Model identifier (default: `gemini-nano` on device, `gemini-2.5-flash` in the cloud)          |
| `apiKey`         | `string`                   | Gemini API key - required for `gemini` only                                                   |
| `availableTools` | `Record<string, Tool>`     | Tools whose `execute` handlers ADK can call. See [Tool Calling](./generating.md#tool-calling) |
| `nano`           | `AdkNanoModelConfig`       | Gemini Nano model selection. See [Model Selection](#model-selection)                          |

## Errors

Errors thrown by the provider have a `code` from `AdkErrorCodes`:

```typescript
import { AdkErrorCodes, type AdkError } from '@react-native-ai/adk'

try {
  await adk.prepareNano()
} catch (error) {
  if ((error as AdkError).code === AdkErrorCodes.ModelDownloading) {
    // Try again later
  }
}
```

| Code                      | Meaning                                                                 |
| ------------------------- | ----------------------------------------------------------------------- |
| `UNSUPPORTED_PLATFORM`    | Called on iOS or web                                                    |
| `MODEL_UNAVAILABLE`       | Gemini Nano is not supported, or AICore needs an update                 |
| `MODEL_DOWNLOADING`       | The system is still downloading Gemini Nano                             |
| `DOWNLOAD_FAILED`         | The Gemini Nano download failed                                         |
| `INVALID_MESSAGE`         | The prompt has an unsupported part, such as a remote file URL           |
| `INVALID_SCHEMA`          | The response schema cannot be converted for Gemini                      |
| `CONTEXT_WINDOW_EXCEEDED` | The prompt is too long for the model                                    |
| `RATE_LIMITED`            | AICore is busy, the app's quota ran out, or the Gemini API returned 429 |
| `BACKGROUND_USE_BLOCKED`  | Gemini Nano was called while the app was in the background              |
| `GENERATION_ERROR`        | Any other generation failure                                            |
