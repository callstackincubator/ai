Run Gemini Nano on Android, on the device, with the Vercel AI SDK. The provider
wraps Google's [ML Kit GenAI](https://developers.google.com/ml-kit/genai) libraries
directly. Android serves the models through AICore, so there's no model to
bundle and no API key.

It covers:

- [Generating text](/docs/android/generating), streamed or not, with images,
  system instructions and thinking mode (`genai-prompt`)
- [Tool calling](/docs/android/tools) with your own AI SDK tools (`genai-prompt`
  function calling, Gemini Nano 4)
- [Transcription](/docs/android/transcription) of audio files
  (`genai-speech-recognition`)
- [Embeddings](/docs/android/embeddings) (`genai-embedding`)

## Installation

<PackageManagerTabs command="install @react-native-ai/android ai" />

The AI SDK needs its [polyfills](/docs/polyfills). To define tools with zod
schemas, as in the [tools](/docs/android/tools) examples, also install `zod`.

## Requirements

- Android with `minSdkVersion` 26 or higher
- Kotlin 2.4 or newer, which the current ML Kit GenAI libraries are built with
- React Native 0.76 or newer, with the New Architecture
- A physical device with AICore support and a locked bootloader. See the
  [ML Kit GenAI documentation](https://developers.google.com/ml-kit/genai#feature-device)
  for the supported devices. Emulators and device clouds such as Firebase Test
  Lab have no Gemini Nano.

## Native Setup

### Expo

Install the config plugin:

```bash
npx expo install expo-build-properties
```

Set `minSdkVersion` and the Kotlin version with `expo-build-properties`:

```json
{
  "expo": {
    "plugins": [
      [
        "expo-build-properties",
        {
          "android": {
            "minSdkVersion": 26,
            "kotlinVersion": "2.4.0"
          }
        }
      ]
    ]
  }
}
```

Then regenerate the native project:

```bash
npx expo prebuild --clean
```

### Bare React Native

Set `minSdkVersion = 26` and `kotlinVersion = "2.4.0"` in the `ext` block of
`android/build.gradle`.

## Basic Usage

Pass `android()` to the AI SDK. Check that Gemini Nano can run on the device first:

```typescript
import { android } from '@react-native-ai/android'
import { generateText } from 'ai'

if (android.isAvailable()) {
  const { text } = await generateText({
    model: android(),
    prompt: 'Summarize on-device AI in one sentence.',
  })
}
```

[Models and availability](/docs/android/models) covers the availability checks
and downloading Gemini Nano.

## What's Not Supported

The provider only wraps what ML Kit ships. These AI SDK features return an
`unsupported` warning instead:

- Structured output (`responseFormat: { type: 'json' }`, `Output.object`). ML
  Kit only generates structured output for Kotlin classes compiled with its KSP
  processor, not for a JSON Schema at runtime.
- `topP`, `stopSequences`, `presencePenalty` and `frequencyPenalty`
- `toolChoice: 'required'` and a specific tool. Gemini Nano decides whether to
  call a function.

ML Kit's agent library (`genai-agent`) only runs tools declared as Android
App Functions at build time, so AI SDK tools go through the Prompt API's
function calling instead.
