`@react-native-ai/apple` is an AI SDK provider for the AI that ships with iOS.
There are no models to bundle, since it uses the system's models, which run on
device. The system downloads some of them, such as embedding and transcription
assets, on first use. The one exception is the opt-in
[Private Cloud Compute](/docs/apple/models#private-cloud-compute) model.

| Feature                          | Model                        | Apple API               |
| -------------------------------- | ---------------------------- | ----------------------- |
| [Text generation](/docs/apple/generating)  | `apple()`                    | Foundation Models       |
| [Embeddings](/docs/apple/embeddings)       | `apple.embeddingModel()`     | `NLContextualEmbedding` |
| [Transcription](/docs/apple/transcription) | `apple.transcriptionModel()` | `SpeechAnalyzer`        |
| [Speech](/docs/apple/speech)               | `apple.speechModel()`        | `AVSpeechSynthesizer`   |

## Installation

<PackageManagerTabs command="install @react-native-ai/apple ai" />

The provider works with AI SDK v7 and needs its [polyfills](/docs/polyfills).
Examples with schemas also use `zod`.

## Requirements

- React Native New Architecture
- iOS 26 for text generation and transcription, on a device with Apple
  Intelligence turned on. Embeddings and speech work on older versions.
- Xcode 27 to build with the iOS 27 features. Older SDKs leave them out, see
  [iOS Versions](/docs/apple/ios-versions).

## Usage

```typescript
import { apple } from '@react-native-ai/apple'
import { generateText } from 'ai'

if (apple.isAvailable()) {
  const { text } = await generateText({
    model: apple(),
    prompt: 'Explain quantum computing in simple terms.',
  })
}
```

`isAvailable()` is `false` when the device is not eligible, Apple Intelligence
is off, or the model is still downloading. [`getModelInfo()`](/docs/apple/models#availability-and-model-info)
tells you which. Before iOS 26, `isAvailable()` is `false` and `getModelInfo()`
rejects with `UNSUPPORTED_OS`.

To test in the iOS Simulator, turn on Apple Intelligence on your Mac first, see
[Running on Simulator](/docs/apple/running-on-simulator).
